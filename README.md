Cada matéria possui uma pasta própria. Dentro dela serão adicionados os conteúdos e atividades correspondentes.

A estrutura segue a organização:

Portfólio → Matéria → Atividade → Arquivos

---

## Arquitetura da Informação

A organização deste portfólio utiliza conceitos de Arquitetura da Informação:

**Classificação:** separação das atividades de acordo com cada matéria.

**Taxonomia:** organização hierárquica entre o portfólio, as matérias e suas atividades.

**Metadados:** informações utilizadas para identificar e descrever cada atividade.

**Navegação:** utilização de links para facilitar o acesso entre as diferentes partes do portfólio.

**Encontrabilidade:** organização e nomeação dos conteúdos para facilitar sua localização.

**Relações entre conteúdos:** ligação entre atividades e conteúdos que possuem relação entre si.
